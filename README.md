## 🚀 Featured Projects

### 1. Bulk Email Sender Pro
A full-stack bulk email campaign platform built to handle large-scale email operations with personalization and campaign tracking.

- Built with React, FastAPI, PostgreSQL, and AWS SES.
- Google OAuth authentication and JWT-based authorization.
- CSV validation, duplicate detection, and personalized email templates.
- Campaign tracking with sent/failed reports.
- Tested with **10,000+ email sends** during the company evaluation.

**Tech:** React · FastAPI · PostgreSQL · AWS SES · Google OAuth

[Live Demo](https://mail.ankur.in) · [Repository](https://github.com/Ankur-akr/bulk-email-sender-v2.0)

### 2. PrepTrack
A DSA progress tracking platform that helps developers organize and analyze their problem-solving journey across multiple coding platforms.

- Track problems from LeetCode, Codeforces, HackerRank, and GeeksforGeeks.
- Visualize topic-wise and difficulty-wise progress.
- Maintain notes, streaks, and weekly goals.
- Smart insights to identify weak topics and revision gaps.

**Tech:** React · Vite · Firebase · Firestore · Recharts

[Live Demo](https://preptrack.ankur.in) · [Repository](https://github.com/Ankur-akr/PrepTrack)

### 3. IndiaVotes
An interactive election awareness platform designed to explain the Indian electoral process through simulations and educational content.

- Interactive EVM and VVPAT voting simulation.
- Simulated VVPAT slip with a 7-second display.
- Election process timeline, quizzes, FAQs, and voter awareness content.

**Tech:** React · Firebase

[Live Demo](https://indiavotes.ankurrai.in) · [Repository](https://github.com/Ankur-akr/election_process)

### 4. AI Resume Job Matcher
An AI-powered application that uses semantic similarity to match resumes with job descriptions.

- Uses vector search for semantic matching.
- Integrates Endee Vector Database and Groq Llama 3.
- Includes a fallback mechanism for matching workflows.

**Tech:** Python · Endee Vector Database · Groq · LLMs

[Repository](https://github.com/Ankur-akr/endee/tree/master/resume-matcher)

### 5. Smart Classroom for Rural Colleges — SIH 2025
A prototype developed for **Smart India Hackathon 2025**, addressing the challenge of remote classrooms for rural colleges.

- Student and faculty dashboard prototype.
- Proposed low-bandwidth virtual classroom experience.
- Solution concept includes synchronized slides, compressed audio, offline access, and a low-cost Online Classroom Device (OCD).

**Tech:** Web Development · Smart Education · IoT Concept

[Repository](https://github.com/Ankur-akr/Sih)
